# SmartFit Gym Application

Welcome to the SmartFit Gym ASP.NET Core MVC application!

## Purpose
SmartFit Gym is a comprehensive web-based gym management system designed to streamline operations for fitness centers. The application provides features for member registration and management, workout tracking, membership plan administration, and AI-powered workout recommendations. It caters to three main user roles: administrators for overseeing gym operations, trainers for managing client interactions, and members for personal fitness tracking and engagement.

Key features include:
- User authentication and role-based access control
- Member profile management and dashboard
- Workout logging and progress tracking
- Membership plan creation and subscription management
- Administrative tools for managing members and gym operations
- AI-driven personalized workout recommendations
- Contact and support functionality

## Setup Instructions
1. Open the solution in Visual Studio.
2. Build and run the project (the database will automatically initialize and seed on the first run).
