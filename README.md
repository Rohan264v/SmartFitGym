# SmartFit Gym Application

Welcome to the SmartFit Gym ASP.NET Core MVC application!

## Setup Instructions
1. Open the solution in Visual Studio.
2. Build and run the project (the database will automatically initialize and seed on the first run).

## Default Demo Credentials
For testing and evaluation purposes, default accounts are automatically seeded into the database:

### Admin Account (Full Access)
- **Email:** `admin@smartfitgym.com`
- **Password:** `Admin@123`

### Client / Member Account
- **Email:** `client@smartfitgym.com`
- **Password:** `Client@123`

You can use these credentials on the Login page to access the Admin Dashboard. Standard users can create their own accounts via the "Join Now" or "Sign Up" pages.
